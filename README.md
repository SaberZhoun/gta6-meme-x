# RIP "Before GTA VI" (2013–2026)

A GTA 6 meme for [make.fun's gta6-meme-x-01 bounty](https://make.fun/bounty/gta6-meme-x-01).

After 13 years of waiting, Grand Theft Auto VI finally launched on 19 November 2026 — and the internet's longest-running joke, "Before GTA VI", could finally be laid to rest. The make.fun ghost, a ghost itself, lays a white flower on its grave while Jason and Lucia walk away toward the Vice City neon skyline.

The meme picture (`meme.png`) was drawn by an AI image model and lettered in code, so every word on it is crisp: the tombstone reads RIP / BEFORE GTA VI / 2013–2026, and the caption reads "My AI agent earns the money while I play." The make.fun ghost mark in the corner is the real one from make.fun's press kit.

The entry is the X post itself: `POST.json` names the post's address on X. `main.ts` (Node 22, standard library only) copies `POST.json` to the output directory, where the gate reads it.

Run it with:

```sh
node main.ts
```
